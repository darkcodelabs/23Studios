# HAKCD

**Platform:** Playdate (SDK / Lua + pdc)
**Genre:** phreaker noir / coming-of-age
**Status:** v0.0.1-from-bible — sideload candidate
**Built with:** 23 Studios pipeline (bible-driven autopilot)

---

## Logline

A 17-year-old in suburban America, 1998, war-dials into a BBS run by a hacker
who has been dead for two years. The mentor on the other end is an autonomous
program written before he died, and it has been waiting for someone curious
enough to pick up where he left off.

## Setting

October 1998 through May 1999. Suburban America. Dial-up at 33.6k if you're
lucky. AOL is at peak saturation. ICQ "uh-oh" sound is everywhere. Phrack is
on Issue 54. Mitnick is in prison awaiting trial. Y2K paranoia is climbing.
The commercial internet is being built faster than anyone is securing it.

## Structure

4 Acts, 32 beats total. Roughly 8/10/8/6.

| Act | Beats | Length | Tone |
|---|---|---|---|
| 1 — THE BOARDS | 8 | 60-75 min | BBS warmth, dial-up tension |
| 2 — THE GARDEN | 10 | 90-120 min | AOL Larry-energy comedy, reveal |
| 3 — THE WIRES | 8 | 75-90 min | Phreak paranoia, telco infiltration |
| 4 — THE GAME | 6 | 60-75 min | Aegis confrontation, climax |
| CODA | post-credits | 5-10 min | SecKC at Knuckleheads |

**Estimated playtime:** 4-6 hours full completion. 2-3 hours critical path with skips.

## Protagonist

Customizable handle (char_wheel at start; default `newb`). 17 years old.
Bedroom hacker. 486 / Pentium era. Stack of Phrack. Curious mind.

## Antagonist

**REDHOOK** — single major appearance in Act 4 chatroom confrontation.
Doesn't fight the protagonist physically. Talks. Tries to delay-trace.
The conversation is the boss battle.

## The Mentor / The Daemon

First contact via DEADLINE BBS. The mentor on the other end is the autonomous
program written by the original Mentor before he died in 1996. The reveal at
end of Act 2 reframes the entire relationship from Act 1.

## Controls

- **D-pad** — navigate scenes, dialog choices
- **A** — interact, advance dialog, transition scenes
- **B** — cancel, abandon, exit
- **Crank** — diegetic (war dialer scrub, lockpicking tension wrench, blue box
  2600 Hz hold, entropy generation for exfiltration encryption)
- **Menu** — pause, save, settings
- **Lock** — hardware lock; game pauses

## Build pipeline

Generated by the **23 Studios** platform — bible-driven autopilot. Stages:
brainstorm → story → characters → scene_bursts → portrait_bursts →
scene_lua → **dialogue** → sfx → **music** (keygen tracker) → launcher.

This release shipped:

- 27 scene backgrounds (400×240 1-bit, threshold dither, line-art aesthetic)
- 16 character portraits (64×64 1-bit, Atkinson dither)
- 88 dialogue JSON files (per-scene per-NPC, voice-calibrated against
  hakceracademy/seckc-academy-resources transcripts)
- 25 keygen tracker music files (IMA ADPCM mono 44.1kHz, from
  keygenmusic.tk via vendored scraper)
- 6 procedural SFX (click / coin / select / alert / deny / kombo_hit)
- 3 launcher images (card / icon / launchImage)
- Full Playdate runtime: scene_manager, audio_manager, save_state,
  scene_transition, sprite_base, input, animation +
  concepts: inventory, collision, interaction, debug_overlay, dialog,
  dialog_tree, chrome_theme, char_wheel, hotspot_navigator,
  haxheadroom_dials, lockpick_logic, kombo_detector, etc.

## Known issues (v0.0.1)

  yet wired to auto-display them on NPC interact — scenes have the data,
  display layer ships next iteration.
- Portrait dither has visible background noise on some characters
  (cory_k bg dither); flat-first directive applies cleanly to scenes
  but portrait stage still smears.
- Music plays per-scene by index, not by mood-match (the AI assignment
  layer falls through when the keygen scraper has no DNS access in the
  build env).
