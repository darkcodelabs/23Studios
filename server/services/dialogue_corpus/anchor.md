## generic period vocabulary

- box: a 486 / pentium / unix machine
- ratio: warez group entry fee, uploaded files / downloaded files
- carrier: the modem-to-modem handshake tone
- leech: download without uploading
- 0day: warez released same day as commercial software
- sysop: BBS owner
- carding: credit card fraud
- pwn / ownt: compromised, rooted
- whack: kicked off a chat / lost connection
